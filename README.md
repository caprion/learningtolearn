# Learning Nudges

A parent's facilitation guide for structured learning with 9-10 year olds (ICSE Class 4 level).

**Philosophy:** calm, low-friction, parent-led interaction. Use "Learning How to Learn" principles (Oakley) and "Toys from Trash" mechanics (Gupta).

## Quick Start
1.  Open **[Quick Reference](00-Quick-Reference.md)** for one-line prompt summaries.
2.  Pick a subject based on child's energy.
    *   **[Mathematics](01-Mathematics.md):** Market play and Fermi estimates.
    *   **[Science](02-Science.md):** Observation and hypothesis.
    *   **[Geography](03-Geography.md):** Spatial connection.
    *   **[English Literature](04-English-Literature.md):** Perspective and style.
    *   **[The Maker's Lab](06-Makers-Lab.md):** Physical builds (Arvind Gupta style).
3.  Log informally in [Session Rituals](05-Session-Rituals.md).
